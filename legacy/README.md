# 🦃 مزرعه بوقلمون — نسخه اول (Vanilla JS)

> ⚠️ این نسخه قدیمی است و فقط برای مرجع نگهداری می‌شود. نسخه اصلی و فعال پروژه با **React 19 + TypeScript + Vite** در ریشه مخزن قرار دارد.
>
> برای اجرای این نسخه کافی است `index.html` را باز کنید یا `python -m http.server` را در همین پوشه اجرا کنید.

سامانه جامع و کاملاً فارسی برای مدیریت مزرعه پرورش بوقلمون: ثبت فعالیت روزانه، هزینه‌ها، خوراک، فروش، شرکا و گزارش‌ها.

## ✨ امکانات

| بخش | توضیح |
|---|---|
| **داشبورد** | نمای کلی مزرعه، شاخص‌های کلیدی، نمودارها و خلاصه وضعیت |
| **گله‌ها** | ثبت گله، تعداد، وزن، تلفات و پیگیری دوره پرورش |
| **ثبت روزانه** | ورود روزانه مصرف خوراک، تلفات، وزن و وضعیت سالن |
| **هزینه‌ها** | ۱۹ دسته هزینه (آب، برق، گاز، گازوئیل، جوجه، پروار، گوشت، خوراک، واکسیناسیون، کارگر، دارو، تجهیزات و…) با زیردسته |
| **خوراک** | مدیریت خوراک آماده و فرمول ساختگی، دسته‌های تولید و موجودی انبار |
| **فروش** | ثبت فروش گوشت بر اساس نوع (لاشه، ران، سینه، بال، فیله، چرخ‌کرده، جگر) |
| **شرکا** | مدیریت سهام، آورده و تسویه شرکا |
| **انبار** | موجودی اقلام و گردش انبار |
| **وظایف** | تسک‌های مزرعه و واکسیناسیون |
| **گزارش‌ها** | گزارش سود و زیان، بهای تمام‌شده و تحلیل عملکرد |
| **تنظیمات** | نام مزرعه، واحد پول، ارقام فارسی، طول دوره و وزن هدف؛ پشتیبان‌گیری/بازیابی JSON |

## 🚀 اجرا

پروژه کاملاً استاتیک است و به build نیاز ندارد:

```bash
# با پایتون
python -m http.server 8080

# یا با Node
npx serve .
```

سپس در مرورگر باز کنید: <http://localhost:8080>

> باز کردن مستقیم `index.html` با `file://` هم کار می‌کند، اما اجرای یک سرور محلی توصیه می‌شود.

```
        ├── ui.js          # کامپوننت‌ها و ابزارهای رابط کاربری
        ├── charts.js      # نمودارها
        ├── app.js         # مسیریابی و راه‌اندازی
        └── views/         # صفحات (dashboard, flocks, expenses, …)
```

## 💾 ذخیره‌سازی داده

در نسخه فعلی همه داده‌ها به‌صورت محلی در `localStorage` مرورگر با کلید `turkeyFarm.v2` نگهداری می‌شوند:

- ✅ بدون نیاز به سرور یا حساب کاربری
- ✅ آفلاین کار می‌کند
- ⚠️ داده‌ها بین دستگاه‌ها و مرورگرها همگام نمی‌شوند
- ⚠️ پاک کردن داده‌های مرورگر، داده‌های برنامه را هم پاک می‌کند

برای همین از **تنظیمات → پشتیبان‌گیری** به‌صورت دوره‌ای فایل JSON بگیرید.
